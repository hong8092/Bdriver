CH32M030DS2 默认引脚功能总结
=============================

一、调试接口（SWD）
------------------
| 功能 | 引脚 | 说明 |
|------|------|------|
| SWDIO | PA2 | 调试数据输入/输出 |
| SWDCK | PA3 | 调试时钟 |


二、USB 全速接口
----------------
| 功能 | 引脚 | 说明 |
|------|------|------|
| USB_DM | PA11 | USB 数据负极 |
| USB_DP | PA12 | USB 数据正极 |

注意：使用USB功能建议外接8MHz晶振（PB5/PB6）


三、串口 UART（多引脚映射）
---------------------------
| 默认配置 | 引脚 |
|---------|------|
| UART_TX | PA9 |
| UART_RX | PA10 |

其他可映射引脚请参考数据手册


四、I2C 接口（多引脚映射）
-------------------------
默认引脚配置：
| 功能 | 可能引脚 |
|------|---------|
| I2C_SCL | PC2 / 其他映射引脚 |
| I2C_SDA | PC1 / 其他映射引脚 |

注意：CH32M030支持多引脚映射，具体默认引脚请参考数据手册


五、SPI 接口（多引脚映射）
--------------------------
| 功能 | 可能引脚 |
|------|---------|
| SPI_SCK | 参考数据手册 |
| SPI_MISO | 参考数据手册 |
| SPI_MOSI | 参考数据手册 |
| SPI_NSS | 参考数据手册 |


六、ADC 模数转换器
------------------
| 通道 | 引脚 |
|------|------|
| ADC_IN0 | PA0 |
| ADC_IN1 | PA1 |
| ADC_IN2 | PC4 |
| ADC_IN3 | PD2 |
| ADC_IN4 | PD3 |
| ADC_IN5 | PD5 |
| ADC_IN6 | PD6 |
| ADC_IN7 | PD4 |

共20路外部通道


七、OPA 运算放大器（4通道）
--------------------------
| 运放 | 说明 |
|------|------|
| OPA1 | 支持自偏置PGA |
| OPA2 | 支持自偏置PGA |
| OPA3 | 支持单端及差分输入，多档增益 |
| OPA4 | 支持单端及差分输入，多档增益 |

可组合为：
- 2组交流小信号放大解码器（QII1、QII2）
- 2组差分输入电流采样（ISP1、ISP2）


八、MOSFET 半桥预驱动（4对）
---------------------------
| 半桥 | 高端栅极 | 低端栅极 | 自举电源 | 源极 |
|------|---------|---------|---------|------|
| 第0组 | PB8 | PB9 | VB0 | VS0 |
| 第1组 | PB10 | PB11 | VB1 | VS1 |
| 第2组 | PB12 | PB13 | VB2 | VS2 |
| 第3组 | PB14 | PB15 | VB3 | VS3 |

可组合为三相电机驱动或两路独立全桥驱动


九、定时器 PWM 输出
------------------
| 定时器 | 通道1 | 通道2 | 通道3 | 通道4 |
|--------|-------|-------|-------|-------|
| TIM1（高级） | PD2 | PA1 | PC3 | PC4 |
| TIM2（通用） | PD4 | PD3 | PC0 | PD7 |


十、时钟晶振
------------
| 晶振类型 | 引脚 | 说明 |
|---------|------|------|
| 外部晶振 | PB5 / PB6 | 4~25MHz，用于USB等 |
| 内部RC | - | 8MHz（出厂校准）/ 340kHz |


十一、重要注意事项
------------------
1. 具体引脚详细映射表请参考官方数据手册 CH32M030DS0.PDF
2. CH32M030的UART、I2C、SPI均支持多引脚映射
3. USB建议使用外部晶振以保证稳定性
4. 预驱动电源VDD8额定电压：5~10V
5. 通用I/O电源VDD33额定电压：3.3V
