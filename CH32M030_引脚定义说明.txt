CH32M030DS2 引脚功能定义
=========================

一、芯片基本信息
----------------
- 内核：青稞 RISC-V3B
- 主频：最高 72MHz
- SRAM：12KB
- Flash：64KB
- 封装：LQFP48 / QFN48 / QFN32 / QSOP28


二、调试接口
------------
SWD 调试引脚（通过 WCH-LinkE 下载）：
- PA2：SWDIO（调试数据输入/输出）
- PA3：SWDCK（调试时钟）


三、时钟晶振
------------
- 内部 RC：8MHz（出厂校准）
- 内部 RC：340kHz
- 外部晶振：4~25MHz
- 推荐 USB 使用外部晶振
- PB5/PB6：外部晶振引脚


四、USB 全速接口
----------------
- 内置 USB2.0 PHY
- 支持 USB Host 和 USB Device
- 支持 PDUSB 快充
- 支持 BC1.2、DCP/CDP 充电协议
- 需要外部晶振（推荐 8MHz）


五、通信接口
------------

5.1 UART（多引脚映射）
    - 默认：PA9(TX) / PA10(RX)
    - 可映射到其他引脚

5.2 I2C 接口
    - 默认引脚需要查看数据手册
    - 支持多引脚映射

5.3 SPI 接口
    - 默认引脚需要查看数据手册
    - 支持多引脚映射


六、电机驱动相关
----------------

6.1 四对 N型 MOSFET 半桥预驱动
    - 可组合为三相电机驱动
    - 可组合为两路独立全桥驱动
    - 内置自举二极管
    - 驱动引脚（示例，参考数据手册）：
      * 第一组半桥：VB0, VS0, PB8, PB9
      * 第二组半桥：VB1, VS1, PB10, PB11
      * 第三组半桥：VB2, VS2, PB12, PB13
      * 第四组半桥：VB3, VS3, PB14, PB15

6.2 预驱动供电
    - VDD8：5~10V 额定电压


七、模拟外设
------------

7.1 OPA（运放）- 4通道
    - OPA1/OPA2：支持自偏置 PGA
    - OPA3/OPA4：支持单端及差分输入
    - 可组合为交流小信号放大解码器（QII）
    - 可组合为差分输入电流采样（ISP）

7.2 CMP（比较器）- 3通道
    - CMP1：支持数字滤波
    - CMP2/CMP3：支持 N端偏置可选

7.3 ADC - 12位
    - 20路外部通道
    - 模拟输入范围：GND ~ VDD33


八、通用定时器
--------------
- TIM1：16位高级控制定时器（带死区控制、紧急刹车、PWM互补输出）
- TIM2：16位通用定时器
- TIM3：16位精简通用定时器
- WWDG：窗口看门狗
- SysTick：系统时基定时器


九、可编程电流模块
-----------------
- 2组 10位可编程灌电流模块
- 2组源电流模块


十、电源相关
------------
- VHV：高压电源输入（5~28V）
- VDD8：预驱动 I/O 电源（5~10V）
- VDD33：普通 I/O 和 ADC 电源（3.3V）


十一、GPIO 端口
---------------
- 共 37 个 I/O 口
- 映射 16 个外部中断
- 8个 MV（中等电压）预驱动引脚
- 2个 HV（高压）引脚
